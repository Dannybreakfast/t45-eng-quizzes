# Answer key

1. **C** — 10,000. Quizlet set 783149178, card #1 (verbatim).
2. **B** — Eject. Quizlet set 783149178, card #2 (verbatim).
3. **B** — GEN switch off. Quizlet set 783149178, card #3 (verbatim).
4. **C** — Maintain a/s less than 200 KIAS. Quizlet set 783149178, card #4 (verbatim).
5. **D** — Altitude descend below 25K, AIR FLOW knob off. Quizlet set 783149178, card #5 (verbatim). NOTE: Older gouge — differs. IC 21/43 SMOKE OR FUMES: 1. Mask – on/tight 2. Initiate controlled descent to below 18,000 feet MSL 3. Air Flow Knob – Off; if unable to clear/see: Airspeed – reduce, warn occupant/secure items, Seat – lower, MDC Firing Handle – pull.
6. **C** — Hook down, land 50 ft prior. Quizlet set 783149178, card #6 (verbatim).
7. **D** — Return flaps to previous position. Quizlet set 783149178, card #7 (verbatim).
8. **C** — OBOGS/ANTI-G switch off. Quizlet set 783149178, card #8 (verbatim). NOTE: Older gouge — differs. IC 21/43 OXYGEN WARNING LIGHT (in-flight): 1. Throttle – Set minimum 80% rpm 2. Execute Adverse Physiological Symptoms (as required).
9. **B** — Rudder (counter swerve) and go around if able. Quizlet set 783149178, card #9 (verbatim). NOTE: IC 21/43 LOSS OF DIRECTIONAL CONTROL: go-around if flyaway airspeed available; otherwise abort; blown tire: brakes release, anti-skid off, brakes apply gradually.
10. **D** — All the above. Quizlet set 783149178, card #10 (verbatim).
11. **A** — Blinking screen, invalid display, blank screen, stuck push button. Quizlet set 783149178, card #11 (verbatim).
12. **B** — Use radar alt if below 5K AGL, use cabin altimeter if unpressurized, and check PITOT Heat is on. Quizlet set 783149178, card #12 (verbatim).
13. **B** — Eject. Quizlet set 783149178, card #13 (verbatim).
14. **C** — Pull Emerg. Oxygen actuator, throttle off, GTS button, idle. Quizlet set 783149178, card #14 (verbatim). NOTE: IC 21/43 AIRSTART: 1. Emergency oxygen green ring(s) – pull 2. Throttle – off; simultaneously 3. GTS Start Button – Press 4. Throttle – Idle; if no relight within 30 s / EGT exceeds limits: 5. Throttle – off (30 s drain); repeat *3/*4 if above 13% RPM and 250 KIAS.
15. **B** — ARI, SBI, yaw dampner, and rudder trim. Quizlet set 783149178, card #15 (verbatim).
16. **C** — Emergency engine shutdown. Quizlet set 783149178, card #16 (verbatim). NOTE: IC 21/43 GTS FIRE WARNING LIGHT – GROUND: Execute emergency shutdown/egress; IN-FLIGHT: Engine switch – off.
17. **B** — Descend below 25K MSL. Quizlet set 783149178, card #17 (verbatim). NOTE: Gouge item (CABIN ALT/pressurization). Don't confuse with IC 21/43 RAPID DECOMPRESSION: green ring(s) pull, OBOGS flow selector(s) off, descend below 10,000 ft cabin altitude.
18. **D** — IDLE, Neutralize, monitor. Quizlet set 783149178, card #18 (verbatim). NOTE: Older gouge — differs. IC 21/43: 1. Throttle – idle 2. EGT/RPM – check (no 'neutralize' step).
19. **B** — Rudder (counter swerve), Anti-skid off. Quizlet set 783149178, card #19 (verbatim). NOTE: IC 21/43 ABORT + LOSS OF DIRECTIONAL CONTROL (blown tire): Brakes – release, Anti-skid switch – off, Brakes – apply gradually.
20. **B** — flared, half flap. Quizlet set 783149178, card #20 (verbatim).

24. **C** — Below 25K, 13%, N2 min 250 kts. Quizlet set 783149178, card #24 (verbatim). NOTE: IC 21/43 AIRSTART: repeat steps *3/*4 if above 13% RPM and 250 KIAS.
25. **B** — Idle, extend, brakes as req, hook 1000 ft prior. Quizlet set 783149178, card #25 (verbatim). NOTE: IC 21/43 ABORT adds step 5: Brakes – release prior to crossing the arresting gear.

29. **D** — Divert to shore, min. descent rate landing with arresting wires removed. Quizlet set 783149178, card #29 (verbatim).
30. **B** — Confirm engine operation, reset Gen switch. Quizlet set 783149178, card #30 (verbatim).

34. **B** — Release brakes, anti-skid off, brakes as required. Quizlet set 783149178, card #34 (verbatim). NOTE: IC 21/43 BRAKE FAILURE – ASHORE/SKID: Throttle – idle, Brakes – release, Anti-skid switch – off, Brakes – apply gradually.

36. **C** — Idle, instruments check, secondary-eject. Quizlet set 783149178, card #36 (verbatim). NOTE: Older gouge — differs. IC 21/43 FIRE WARNING LIGHT in-flight: 1. Throttle – minimum for safe flight 2. Check for secondary indications; eject if fire confirmed or flight control lost; else land as soon as possible.
