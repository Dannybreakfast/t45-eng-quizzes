---

# Answer key

1. **B** — Clearance Delivery has no control function; IFR clearance delivery only.
2. **C** — ARTCC is central authority for IFR clearances.
3. **B** — FSS common freqs 122.2 and 255.4.
4. **B** — Training command: read back all clearances verbatim.
5. **C** — Report level-off when in RVSM (FL290–FL410).
6. **B** — Lost comms: squawk 7600.
7. **C** — Guard 243.0 and 121.5.
8. **B** — Avoid extended IFR in ATC system in VMC; land ASAP.
9. **B** — AVEF = Assigned, Vectored, Expected, Filed.
10. **B** — Highest of Assigned / Minimum IFR / Expected (AME).
11. **B** — WARNING: get expected further routing first.
12. **B** — No EFC → as close as possible to ETA (T/O + ETE).
13. **C** — Emergency: squawk 7700.
14. **B** — PAN-PAN = urgency; MAYDAY = distress.
15. **B** — Holding report exception: military terminal + radar contact + instrument training.
